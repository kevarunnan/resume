How it works

This page runs entirely in your browser. The left panel holds your inputs; JavaScript keeps a small state object in sync and updates the right-hand preview as you type. Your profile photo is read with the File API and shown as a data URL in the preview. PDF export uses html2pdf.js to rasterize the preview and build an A4 PDF.

How to use

  1. Fill in Personal Info (name, email, phone, location) and upload a profile photo if you like.
  2. Add your summary, comma-separated skills, and experience; the preview updates immediately.
  3. Click Download PDF to save the preview as a PDF.
